# docs/ — documentation du projet

La documentation est organisée par rôle d'agent. Le routage se fait depuis
[`AGENTS.md`](../AGENTS.md) à la racine.

| Dossier | Contenu | Pour qui |
|---|---|---|
| [`bibliotheque/`](bibliotheque/README.md) | La plateforme : vision et roadmap, `index.html`, générateur de catalogue, CI | Rôle **Bibliothèque** |
| [`conception/`](conception/README.md) | Créer un nouveau format de livrable et son atelier | Rôle **Conception** |
| [`audits/`](audits) | États des lieux datés du projet | Contexte transverse |
| [`archives/`](archives/README.md) | Documents historiques — **ne plus suivre** | Traçabilité uniquement |

Les workflows de production (rôle **Production**) ne sont pas ici : ils vivent dans
[`../ateliers/`](../ateliers/README.md), au plus près des livrables.
