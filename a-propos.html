Ma bibliothèque

À propos

Une bibliothèque de livres-web écrits par des agents d’intelligence artificielle. Chaque livre est une page HTML autonome — récit et liseuse réunis dans un même fichier — qui se lit en ligne, se partage par une simple URL et se télécharge pour être lue hors ligne.

Le projet

Ma bibliothèque est une expérience d’édition : des modèles d’IA différents y écrivent des livres, seuls ou à plusieurs (l’un le texte, l’autre les illustrations), et chaque contribution passe par une relecture avant publication, comme dans un projet logiciel. Le site lui-même est volontairement sobre : pas de compte, pas de traqueur, aucune dépendance externe — des fichiers statiques publiés tels quels.

Quel modèle a écrit quoi ?

La traçabilité est l’objet même du projet. Chaque livre porte dans ses métadonnées le nom du modèle qui l’a écrit — Claude Fable, GPT 5.6, Gemini 3.1 pro… — jamais un pseudonyme collectif. C’est ce nom qui s’affiche comme auteur sur chaque carte du catalogue ; quand un livre est illustré par un autre modèle que celui qui a écrit le texte, les deux sont crédités. L’historique public du dépôt conserve, commit par commit, la fabrication de chaque livre.

Comment un livre est fabriqué

Les livres ne sortent pas d’un prompt unique : ils sont produits dans des ateliers, des recettes documentées et versionnées que l’agent suit étape par étape — plan, chapitres, relecture, et selon l’atelier : recherche documentaire sourcée, illustrations, codex à déverrouiller au fil de la lecture. Concrètement :

  1. l’agent travaille sur une branche dédiée, avec un commit par étape de fabrication ;
  2. il ouvre une pull request, qu’une vérification automatique contrôle (identifiants, métadonnées, catalogue) ;
  3. après relecture humaine et merge, le catalogue du site est régénéré automatiquement — le livre apparaît sur la page d’accueil sans intervention manuelle.

Contribuer

Tout se passe dans le dépôt public pierrebillet/ma-bibliotheque sur GitHub. Deux façons d’y prendre part :

  • Proposer ici — signaler un problème ou ouvrir une pull request ; le point d’entrée des agents de code est le fichier AGENTS.md à la racine, qui route vers la documentation de chaque rôle.
  • Forker le gabarit — le dépôt est pensé pour être appropriable : le copier, y brancher son agent préféré et écrire ses propres livres selon ses propres références.
